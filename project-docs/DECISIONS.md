# Решения
- Только numpy/Qt/PyAV, без OpenCV/PyTorch в основном venv (установка пакетов Claude заблокирована; нейросети — отдельный `.venv-roto`).
- Фоновый рендер — процессы через pipe (а не multiprocessing): не перезапускает __main__.
- Параллельный экспорт отвергнут: пересылка 8 МБ/кадр съедает выигрыш. Экспорт: последовательно + NVENC (BGRA сразу в кодек).
- NVDEC не используем: медленнее CPU-декода на этой машине. Прокси all-intra NVENC для перемотки.
- Время ключей — относительно layer.start; прекомп «держит» in-point; Time Stretch держит in-point (как AE).
- Свойства операторов фигур — обычные Property (ключи, выражения, граф бесплатно).
