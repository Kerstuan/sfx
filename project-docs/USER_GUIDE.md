# SFX — руководство пользователя

Видеоредактор и инструмент моушн-дизайна с монтажом в духе CapCut.
Python + Qt (PySide6), видео декодирует PyAV, экспорт идёт через ffmpeg.

## Запуск

```bash
./run.sh                 # пустой проект
./run.sh видос.mp4       # сразу с роликом
./run.sh проект.skl      # открыть проект
```

При первом запуске `run.sh` сам создаст `.venv` и поставит зависимости. Нужен `ffmpeg` в системе.

## Что умеет

**Интерфейс как в AE.** Сверху панель инструментов с переключателем «Прилипание» и рабочими средами
(По умолчанию / Анимация / Эффекты / Звук / Минимум). Слева вкладки «Проект» и «Эффекты слоя» (Effect Controls, F3).
Справа сворачиваемые панели: Предпросмотр, Свойства слоя, Выравнивание, Звук, Эффекты и шаблоны.
В пустой композиции стартовый экран «Новая композиция» / «Новая композиция из видео».
Раскладка панелей и размер окна запоминаются при закрытии и восстанавливаются при следующем запуске.

**Инструменты:**

| Клавиша | Инструмент |
|---|---|
| V | выделение (тянуть вершины масок и контуров) |
| H | рука |
| Z | лупа |
| W | поворот |
| C | облёт камеры: средняя кнопка — сдвиг, правая или колесо — наезд |
| 3D-вид (список под вьювером), F10 / F11 / F12 | **виды как 3D View в AE:** Активная камера, Спереди, Слева, Сверху, Сзади, Справа, Снизу (ортогональные) и Свой вид. В них видны камеры (значок + линия к точке интереса) — клик по значку выделяет камеру, её можно двигать стрелками гизмо. Колесо мыши в этих видах — масштаб вида; инструмент C: в «Своём виде» облёт (Shift/средняя кнопка — сдвиг), в ортогональных — сдвиг вида. Перетаскивание 3D-слоя мышью в виде «Сверху» двигает его по X/Z. При первом открытии ортогональный вид сам вписывает сцену. **Рендер в файл всегда идёт через активную камеру**, вид — только для расстановки. F10 — спереди, F11 — свой вид, F12 — активная камера |
| Раскладка видов (список «1 вид / 2 вида / 4 вида» под вьювером, меню «Вид») | как Select View Layout в AE: рядом с главным вьювером появляются виды Сверху / Спереди / Справа. У каждой панели свой список видов; колесо — масштаб, тянуть — сдвиг, в «Своём виде» — облёт (Shift — сдвиг). Тонкие серые контуры показывают 3D-слои, стоящие к виду ребром. Боковые виды не пересчитываются во время проигрывания и не меняют проект; раскладка запоминается |
| W + 3D-слой | **кольца поворота**: красное — X Rotation, зелёное — Y Rotation, синее — Z Rotation. Тяни вдоль кольца: сдвиг на радиус кольца ≈ 57°, Shift — шагом 45°. Меняется только своё свойство, при секундомере ставится ключ |
| V + 3D-слой | **гизмо осей**: у выделенного 3D-слоя (и у света) во вьювере стрелки X (красная), Y (зелёная), Z (синяя). Тяни стрелку — слой двигается только по этой оси; Alt — точнее. При включённом секундомере Position ставится ключ. Когда ось Z смотрит прямо в камеру, её стрелка рисуется по диагонали вверх-вправо (тянуть вверх-вправо — дальше от камеры) |
| Y | опорная точка (Pan Behind) |
| Q | прямоугольник → эллипс → звезда: на выделенный слой рисуется маска, иначе фигура в шейп-слой |
| G | перо |
| Ctrl+T | текст |

**Слои и свойства:**
- Импорт видео, картинок и звука (Ctrl+I или перетащить в окно). Первый ролик подстраивает композицию под себя.
- **Где встаёт новый слой** (как настройка AE «Create Layers at Composition Start Time»): по умолчанию — в начало композиции (0:00), а не под курсор. Курсор запоминается в проекте, и раньше после повторного открытия новые клипы вставали, например, на 6,4 с. Отключить: «Правка → Создавать слои в начале композиции». При перетаскивании на таймлайн слой встаёт туда, куда его отпустили; несколько файлов — друг за другом.
- **Окно «Проекты»** (Файл → Проекты (главный экран)…, и при запуске без файла): «Новый проект», «Открыть проект…» и список проектов — недавние, все `.skl` из `~/Eddits` и автосохранения, с временем сохранения («только что», «5 мин назад», дата), размером и путём. Двойной клик — открыть. Пропавший файл показан серым; при открытии программа предложит убрать его из списка. Галка «Показывать при запуске».
- Слои: видео, картинка, звук, текст, солид, шейп-слой, камера, корректирующий.
- В таймлайне группы как в AE: Маски, Содержимое, Эффекты, Трансформирование (с «Сброс»), Звук (уровни и волна).
  У свойств есть навигатор ключей ◀ ◆ ▶ и значок «показать в граф-эдиторе».
- Ключи: linear / Easy Ease / ease in / ease out / hold.
- Пререндер (RAM Preview, Num 0): рабочая область просчитывается в память и играет без тормозов; зелёная полоска
  над линейкой — готовые кадры; кэш сбрасывается сам при любом изменении. Пробел играет из кэша.
- Рабочая область: B — начало, N — конец, Ctrl+Alt+B — по выделенным слоям, **двойной клик по полосе рабочей области — вся композиция**.
  **Полоса над линейкой тянется мышью:** синие ручки по краям — начало и конец, середина — сдвиг всей области (с прилипанием к краям клипов, маркерам и курсору; Ctrl+Z отменяет). Пробел играет по кругу внутри рабочей области.
  Рендер по умолчанию берёт рабочую область (поле «Диапазон» в диалоге) — если начало видео не попало в файл, проверь её.
- **Рендер любой композиции:** в диалоге рендера (Ctrl+M) поле «Композиция» — по умолчанию открытая, можно выбрать прекомп, не открывая его. То же — ПКМ по композиции в «Проекте» или по слою-прекомпу → «Рендер композиции…».
- Клик по пустому месту дорожки снимает выделение (раньше выделял клип, если он нарезан из длинного видео). Серая «тень» исходника для slip-монтажа видна и тянется только у выделенного клипа.
- «Эффекты слоя»: при клике по нижнему эффекту, галке fx, сбросе и т. п. список больше не прыгает наверх.
- Выделение слоёв: клик, Ctrl+клик — добавить/убрать, **Shift+клик — все слои от выделенного до щелчка**.
- Маркеры: `*` (цифровая клавиатура) — **без выделения ставит маркер композиции** (флажок на линейке), **при выделенных слоях — маркер на каждом выделенном слое** (флажок на полоске слоя, едет вместе со слоем, при разрезании остаётся в своей половине) — как в AE. Тянуть — переместить, Ctrl+клик — удалить, двойной клик — имя. J/K переходят по ключам и маркерам, слои липнут к маркерам. «Композиция → Удалить все маркеры» убирает и маркеры слоёв.
- **Удалить со сдвигом (Ripple Delete), Shift+Del:** удаляет выделенные слои и сдвигает влево всё, что начиналось после них (дыры не остаётся). Слои, перекрывающие удалённый кусок, не двигаются.
- **Правка → Поднять / Извлечь рабочую область (Lift / Extract Work Area), как в AE:** вырезает кусок рабочей области (B…N) из выделенных слоёв (если ничего не выделено — из всех незаблокированных). Слой, проходящий через область, делится на две части. «Поднять» оставляет дыру, «Извлечь» сдвигает всё после области влево. Заблокированные слои (Ctrl+L) не трогаются. Отменяется Ctrl+Z.
- Slip: тяни серую «тень» исходника вокруг клипа — клип стоит на месте, видео внутри сдвигается.
- Стоп-кадр (Shift+Alt+F): держать кадр N секунд, потом клип играет дальше с того же кадра; галка «Сдвинуть следующие клипы» отодвигает остальной монтаж. Звук клипа на паузе молчит и дальше идёт синхронно.
- Скорость:
  * кадры превью считают фоновые процессы (sfx/render_worker.py, 4 шт.) — окно не подвисает;
    пока полный кадр считается, показывается черновик в пол-разрешения (Adaptive Resolution);
  * прокси (sfx/proxy.py): при импорте видео ≥720p видеокарта (NVENC) делает копию в пол-размера,
    где каждый кадр ключевой — прыжки и шаг назад ~20 мс вместо ~250 мс; ~/.cache/sfx/proxies,
    меню «Композиция → Прокси…»; рендер в файл всегда из оригинала;
  * размытие: пирамида + точный гаусс; в фоновых процессах малые радиусы на GPU (OpenGL, sfx/gpu.py);
  * звук сводится кусками во время проигрывания — Play стартует сразу;
  * рендер в файл: H.264/H.265 на NVIDIA (NVENC), кадры BGRA идут в видеокарту без перевода на CPU.
  SFX_WORKERS=0 — без фоновых процессов, SFX_GPU=0 — без OpenGL.
- Ctrl+C / Ctrl+X / Ctrl+V: эффект (с ключами) → на выделенные слои, ключи → от текущего кадра, слои → копии.
- Пререндер в фоне (Cache Frames When Idle): через 0,6 с простоя кадры сами считаются в память; галочка в «Предпросмотре».
- Фильтры: Порог (Threshold), Постеризация, Уровни, Экспозиция, Чёрно-белое, Сочность, Фотофильтр, Цветовой баланс,
  Выделение краёв, Тиснение, Цифровой сбой (Glitch), Зеркало.
- Keylight (хромакей) с пипеткой ⌖, Gradient Ramp (линейный/радиальный). Пипетка берёт цвет на входе эффекта.
- Панель Flow (F4, как плагин Flow): кривая сегмента с ручками и живым превью, 30 пресетов (Sine…Expo, Circ, Back с перелётом),
  свои пресеты (+), «Применить» (Ctrl+Shift+F), «Прочитать» с ключей (Ctrl+Alt+Shift+F), ввод cubic-bezier из CSS.
- Граф-эдитор (Shift+F3 или Alt+F3): кривые значений с ручками; в графике скорости ручки тянутся
  (влияние и скорость). «Все видимые» показывает все раскрытые кривые.
- Прилипание с Shift (или галкой «Прилипание»): к ключам, краям слоёв, курсору и рабочей области.

**Выражения** на JavaScript, как в AE:
- Alt+клик по секундомеру или Alt+Shift+=. Pickwhip — тянуть спираль на другое свойство.
- Доступно: `time`, `value`, `wiggle()`, `loopOut()`/`loopIn()`, `linear`/`ease`, `random`,
  `thisComp.layer("Имя").effect("Слайдер")("Слайдер")`, `valueAtTime()`, `key(n)` и т. д.
- Контролы для выражений: слайдер, угол, флажок, цвет, точка.

**Маски и шейпы:**
- Маски: сложение, вычитание, пересечение, разность; инверсия, растушёвка, расширение, непрозрачность.
  Контур анимируется ключами.
- Шейп-слои: прямоугольник, эллипс, звезда, контур пером; заливка и обводка.

**3D:** переключатель ⬚ у слоя даёт Z, ориентацию и повороты X/Y/Z. Камера (Ctrl+Alt+Shift+C) с точкой интереса и зумом.
**Свет и тени (3D):** Слой → Новый свет (Ctrl+Alt+Shift+L): прожектор, точечный, параллельный, окружающий. В «Свойствах слоя» — тип, затухание, «Отбрасывает тени»; на таймлайне «Параметры света» (интенсивность, цвет, конус…). У 3D-слоя — «Параметры материала» (окружающее, рассеянное, блик, глянец, металл) и флажки «Принимает свет / Отбрасывает тени / Принимает тени». У камеры — «Глубина резкости» (фокусное расстояние, диафрагма, уровень размытия). Нет света — 3D-слои показываются как есть.
3D-слои сортируются по глубине.

**Эффекты.** Панель эффектов слоя: «Сброс», подгруппы, списки, флажки, цвета, секундомеры.
- Размытие: Гаусс, направленное, нерезкая маска.
- Стилизация: свечение со стилем, хроматическая аберрация, мозаика, виньетка.
- Цвет: яркость и контраст, тон и насыщенность, тонирование, инверсия.
- Остальное: тряска, вспышка, заливка.

Корректирующий слой (Ctrl+Alt+Y) применяет свои эффекты ко всему, что под ним.

**Звук:**
- Звук в превью, время превью идёт по звуковым часам.
- «Уровни звука» с ключами и волна на таймлайне (L).
- Индикатор громкости в панели «Звук».
- Аудиоэффекты:
  - параметрический эквалайзер с кривой, точки тянутся мышью;
  - срез НЧ/ВЧ, басы и верха;
  - компрессор, реверберация, задержка;
  - высота тона, шумоподавление, баланс.
- Аудиоэффекты попадают и в превью, и в рендер.

**Рендер** (кнопка «⏺ Рендер» или Ctrl+M):
- форматы: MP4, MOV, MKV, WebM, GIF, PNG-секвенция;
- кодеки: H.264, H.265, AV1, VP9, ProRes 422 / 4444, QuickTime Animation;
- качество от черновика до «без потерь», свой fps, размер, прозрачный фон.

**Композиции:**
- Несколько композиций в проекте, вкладки над таймлайном, новая композиция (Ctrl+N).
- Прекомпоновка (Ctrl+Shift+C); двойной клик по прекомпу открывает его.
- В «Проекте» композиции и файлы; их можно перетащить в окно композиции или на таймлайн.
- Замена исходника слоя.

**Слои:**
- Нуль-объект.
- «Настройки солида» с размером и пипеткой (Ctrl+Y / Ctrl+Shift+Y).
- Цвет фона композиции (Ctrl+Shift+B).
- Цвета меток слоёв.

**Анимация:**
- Ручки масштаба в окне композиции.
- Меню по правой кнопке, как в AE.
- Шаблоны анимаций: появление/исчезновение, выезды, pop, отскоки, удар зумом, тряска, вспышка, RGB-рывок,
  печатная машинка для текста.
- «Тонирование» в «Тон и насыщенность».

**Ещё:** родитель (Parent), соло, блокировка, размытие в движении, интерфейс на русском и английском,
undo/redo, проект `.skl` (это JSON).

Все хоткеи: **F1** в программе. Работают и на русской раскладке.

## Roto Brush и 3D-трекер камеры (свои движки, без Adobe)
- **Авто-слежение (новое):** выделили объект кистью — нейросеть сама проходит все кадры слоя (вперёд до конца, потом назад). Флажок «Авто» в окне Roto; кнопка «Отследить все кадры».

Ставятся один раз (отдельные окружения, основная программа не тяжелеет):
`~/sfx/install_roto.sh` (PyTorch + SAM 2.1, ~3 ГБ) и `~/sfx/install_tracker.sh` (OpenCV + SciPy, ~120 МБ).

**Roto Brush** — *Инструменты → Roto Brush* (Alt+W). Нейросеть SAM 2.1 (Meta) в отдельном процессе.
1. Выделите видеослой, «Начать для выбранного слоя» (берётся его видимый диапазон).
2. Проведите кистью по объекту (ЛКМ — добавить, Alt+ЛКМ/ПКМ — убрать, Ctrl+колесо — размер кисти).
   Флажок «Кисть по маске» — рисовать прямо по маске для точной правки края.
3. «Отслеживать вперёд/назад». Где ошиблось — поправьте кистью на том кадре и отследите снова.
4. «Сгладить» — убирает дрожание края во времени (с учётом движения).
5. На слое появляется эффект *Roto Brush*: Refine Edge (guided filter — волосы, полупрозрачный край),
   Feather, Choke, Shift Edge, Contrast, Invert, вид Result/Alpha/Overlay.
6. Для After Effects: *Файл → Экспорт*, PNG-секвенция или MOV + ProRes 4444 с альфа-каналом.
Ограничения: тонкие отдельные волоски — частично; быстрые движения и перекрытия требуют правок;
модель tiny и ~4 кадра/с на RTX 3050 (1080p); длинные клипы обрабатываются кусками по 240 кадров.

**3D-трекер камеры** — *Инструменты → 3D-трекер камеры* (Ctrl+Alt+Shift+K). OpenCV + SciPy:
точки Shi-Tomasi + Лукас–Канаде, отсев интерфейса/логотипов, фокус по F-матрицам, E-матрица, PnP,
bundle adjustment. Показывает ошибку репроекции (кадра и средняя), угол обзора и качество.
1. Выделите видеослой → «Анализ». 2. Выберите точки на кадре (клик, Shift+клик, рамка); 3D-вид справа.
3. «Плоскость земли» (≥3 точки на полу), «Начало координат», «Масштаб» (2 точки + расстояние).
4. «Создать камеру» (ключ на каждом кадре), «Нули в выбранных точках», «Текст на плоскости».
5. «Экспорт в After Effects (.jsx)» — в AE: *File → Scripts → Run Script File…* в композиции с этим видео.
Проверено на синтетическом видео с известной камерой: 150/150 кадров, ошибка репроекции 0.6–0.9 px,
фокус ±1.3–3 %, поворот ±0.1–0.3°, траектория ±0.7–1 % длины пути. Ограничения: нужен параллакс (штатив и
панорама — нет глубины), смаз и пустые поверхности мешают, зум объектива во время кадра не поддерживается,
масштаб сцены задаётся вручную. Экспорт .jsx собран по документации AE, в самом AE не проверен (нет AE на Linux).

## Время (Layer → Время / ПКМ → Время)
- **Стоп-кадр с удержанием…** (Shift+Alt+F): кадр под курсором держится заданное число секунд, потом клип играет дальше; слой удлиняется. Длину паузы меняют, двигая ключ «Переназначение времени» на таймлайне.
- **Стоп-кадр до конца слоя** (Freeze Frame) и **Стоп-кадр на последнем кадре** (Freeze on Last Frame) — как в AE.
- **Переназначение времени** (Time Remap, Ctrl+Alt+T): ключи «секунда исходника» в начале и конце слоя; раздвинуть — замедление, сдвинуть — ускорение, ключ-удержание — стоп.
- Эффекты категории **Время**: Постеризация времени (Posterize Time), Эхо (Echo). Плюс уже были: скорость и спид-рамп (Ctrl+R), реверс, смешивание кадров.
- Новые эффекты стилизации: **Deep Glow** (свечение с длинным хвостом, Exposure, Threshold, хроматическая аберрация, Tint) и **Motion Tile**.

## Переходы
- **Эффект → Переходы** (или перетащите из Effects & Presets на слой): ставится на **верхний (входящий) клип** — переход идёт со слоя под ним, у точки входа (In).
- 12 переходов: Растворение, Через цвет, Вспышка, Растворение со свечением / с размытием / с волнами, Зум, Сдвиг, Линейная шторка, Круг, Глитч, Блик объектива.
- **Край:** «Вход слоя» (из клипа ниже) или «Выход слоя» (клип уходит в то, что под ним).
- **Время:** Длительность (кадры), Выравнивание (по центру стыка / начало / конец на стыке), Сглаживание.
- На таймлайне окно перехода заштриховано; потяните его край — меняется длительность.
